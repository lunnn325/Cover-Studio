# 风险清单与降级决策

| ID | 风险 | 严重度 | 必须保护的底线 | 可接受降级 |
|---|---|---|---|---|
| R01 | AirPods HFP/高质量模式、麦克风输出路由耦合 | P0链路 / 高质量P1 | 真实路线、不得错误外放、录制能完成 | 用户选择设备麦克风/传统 AirPods；人声耳返关闭 |
| R02 | 一台设备播放伴奏与同步捕获音视频困难 | P0 | 不损坏原声且可输出可靠成品 | 明示偏移+手动校准，不假称零延迟 |
| R03 | 媒体写入时 App 崩溃、来电、锁屏 | P0 | 已完成片段尽力恢复 | 安全停止、保留恢复入口；不承诺完整最后数秒 |
| R04 | 大工程过度占用 iPhone 空间 | P0 | 禁止无许可删除 | 危险时保护性停止、引导手动归档、顺序导出 |
| R05 | Google Drive Document Picker 只保证本地导出交接 | P0 | 不虚报远端备份成功 | 警告、外部文件回导校验、最终确认才清理 |
| R06 | iPad 处理 AI 需要内存/算力 | P1 | 不影响 iPhone 普通录歌 | 模型不适用就关闭功能/导入现成伴奏 |
| R07 | 免费云端 AI API 不合法/不稳定/收费变化 | P1 | 不得依赖或未经同意上传 | 关闭云 provider，使用本地/已有伴奏 |
| R08 | 自动歌词对齐、逐字时轴错误 | P1 | 不给出假精度 | 退回逐句、粗略滚动、手动校正 |
| R09 | 自动修音产生机械化音色 | P1 | 保留原始干声且默认关闭 | 关停/实验性并提供自然 EQ/混响 |
| R10 | 中断恢复录像可见画面跳切 | P1 | 保留片段与手动裁剪能力 | 显示切点建议，不宣称无痕 |
| R11 | 4K 临时空间/热状态导致导出失败 | P1 | 1080p 可稳定导出 | 不支持的机型隐藏 4K，退回 1080p |
| R12 | iPhone/iPad 编辑同一工程产生分支冲突 | P0 | 不能无提示丢修改 | 安全副本+另存为两份 |
| R13 | 精简包删掉正在引用的旧 Take | P0 | 导入可完整恢复当前编辑 | 强制依赖闭包，禁用不安全排除项 |
| R14 | 多导出同时造成空间翻倍 | P0体验 | 已生成成品不被失败任务连带删除 | 顺序导出、改目标/减少版本 |
| R15 | Windows 开发缺少本地 Xcode 构建能力 | 工程风险 | 不能伪造 IPA | 手动触发 macOS CI，签名凭据用户授权提供 |

风险解除的唯一有效依据是：可查看的编译/测试记录或真实设备测试结果。设计文档本身不解除风险。
