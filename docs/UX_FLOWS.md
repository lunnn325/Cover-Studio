# 页面地图、核心流程与状态行为

## 页面地图

- `Home/Studio`：最近工程卡片 + 新建 + 练习/录制/编辑/作品库四入口；顶端简洁，不堆叠高难度选项。
- `SongSetup`：文件导入 → “已有伴奏/原唱需 AI” → 歌曲名/歌手/伴奏版本 → 变调 ±12 半音 → 歌词 TXT/LRC → 快速开始/更多设置。
- `Practice`：歌词、播放、进度、A-B 循环、变调、练习录音/回听/转 Audio Take。
- `Preflight`：摄像头/麦克风权限、真实输入输出路由、蓝牙录音模式、可用空间、温度警告、可选试录回听、3秒倒计时。
- `Record`：前后镜头录前选择、横/竖、镜像预览、布局记忆；画面和歌词 + 关键进度 + 录制按钮；高级面板可折叠；防误触。
- `Interrupted`：展示暂停原因、已保留片段、等待路由恢复、默认回退预听/手动设置接唱点、恢复/结束。
- `TakePreview`：立即播放刚完成 Take；标记满意、重录、转后期；不必完整渲染 4K 才能预览。
- `Editor`：iPhone 单栏渐进展开、iPad 宽窗多栏预览+轨道+调节；选择 Take，修音/混响/EQ/降噪、音画偏移、字幕、后期照片与补拍。
- `Export`：导出预设 + 带/无字幕 + 音频/stems/工程输出勾选，空间预估、进度分项、失败项单独重试；缺歌词时间轴时提供手动逐句标记入口或只导出无字幕版，不伪造同步字幕。
- `Library`：按歌曲/歌手自动分组，工程/Arrangement/Take 分层；已归档占位、存储占用和恢复入口。
- `Archive`：完整/精简/自定义 → 依赖检查 → 包生成/校验 → Files 目标 → 备份验证级别 → 可选释放空间（双重确认）。
- `Settings`：权限说明、耳返默认、麦克风选择、视频导出预设、录音输出格式、缓存/AI 模型管理、外观跟随系统、错误诊断（无敏感音频）。

## 主流程 A：iPhone 单独录歌

1. 首页 → 录制 → 导入本地**伴奏**或最近工程。
2. 自动沿用该工程歌词/变调/布局，快速模式可立即进入 Preflight。
3. 若 AirPods 支持高质量模式，优先使用并关闭人声耳返；不支持时显示用户可选替代麦克风。列出实际麦克风和实际伴奏输出。
4. 检查设备、存储、温度、电量。可选 5 秒试录回听，不强制；3 秒倒计时。
5. 摄像头和干人声记录在可恢复片段；伴奏播放；时间轴保存实际 host sample timestamps、音频路由变更和歌曲时刻。
6. 录完安全提交 Take → 立即预览 → 可重录或编辑 → 保存双字幕导出预设/分享。

## 主流程 B：iPad 处理 AI，再传 iPhone

1. iPad 导入原曲 → 需要 AI 分离 → 若本地模型不可用则提示安装模型/现有伴奏/有条件的免费云端。
2. 分离展示真实进度；保存原唱/伴奏两轨；试听/重试生成新 Arrangement；导入/校对歌词。
3. 导出「单伴奏」「歌曲准备包」「完整工程」，系统文件选取或 AirDrop，iPhone 导入后独立录制。

## 主流程 C：练习音频制作视频

1. 练习中选区间或完整录音 → 回听满意 → 转为正式 Audio Take。
2. 编辑选择：纯音频输出 / 静态封面或相册图片视频 / App 内补拍对口型视频。
3. 补拍参考：已录制人声+伴奏 / 只有伴奏或节拍。补拍时的音轨不自动取代原始 Audio Take。
4. 预览和手动修正音画同步 → 正常导出。

## 主流程 D：断线/来电/崩溃

- 蓝牙断开：暂停音轨和摄像头写入、完成能完成的片段；不自动从手机扬声器播放伴奏。恢复路由/授权后用户确认，预听回退若干秒，生成新录制片段，不覆盖旧片段。
- 来电/后台/崩溃：保存已完成的片段和日志；重新打开后提示未完成工程，可恢复可用素材或放弃继续；不能保证后台录像或最后零损失。
- 空间过低：分级警告；到危险线停止新写入、尽力完成已有片段；不自动清理原始素材。
- 摄像头权限缺失：提供修复设置或正式纯音频继续。

## 主流程 E：备份、移动、归档

1. 从作品库选工程 → 选完整/精简/自定义 → 估算空间 → 依赖闭包检查 → 生成并验证包。
2. iOS Files Document Picker 选择 Google Drive/iCloud Drive/本地/外部位置，不能声称远端完成上传。
3. 如果用户选择再导入检验：从外部位置重新选中包，做哈希、文件引用和元数据恢复检查（独立恢复副本）；状态升级为“恢复已验证”。
4. 「释放本地空间」显示风险与验证等级，二次确认后仅删除明确选中的本地工程源素材，作品库保留已归档记录；还原需从外部文件重新导入。
5. iPad 已修改工程导回 iPhone：识别 ID+版本/分支冲突 → 先创建备份或安全副本 → 可并存/替换；没有足够空间则拒绝危险覆盖。

## UX 失败状态统一要求

状态始终真实区分：`准备中/运行中/成功/部分成功/失败/能力不可用/需用户操作`。不可将“已排队”“已导出 Files”“远端已验证”混为一谈。失败提供下一步（重试、改设备、改目标、保留原件），不出现静默数据删除。
