# 使用、备份与恢复

## 导入与练习

打开 App，点右上角 +，从系统 Files 选择 MP3、M4A、WAV、AAC、FLAC、AIFF、CAF 或 OGG/Vorbis，填写歌名/歌手并选择「已有伴奏」或「需要去原唱」。后者只保留原曲，目前无已验证 AI 模型，请导入准备好的伴奏作为新版本。App 不自动上传音视频。

OGG/Vorbis 在本机解码为无再次有损压缩的 PCM CAF 播放副本，导入原始 OGG 单独保留；完整/精简/自定义工程包均保留当前伴奏依赖的原件和播放副本。解码需额外本地空间；不会上传音频。OGG/Vorbis 接受 8–192 kHz 单声道/立体声，OGG/Opus、串接/多流 OGG、损坏或不完整文件明确拒绝。扩展名相同不代表编码相同。

练习页可试听、定位、调整伴奏音量和 ±12 半音，速度保持 100%。A/B 标记控制区间循环试听；开始练习录音时关闭循环，按完整时间线保存。纯文本歌词手动滚动，LRC 可逐句定位。歌词编辑页支持粘贴/导入和逐句标记/移动时间点；全部时间点按顺序有效后才开放字幕视频。

满意的练习录音可回听原声或转成正式 Audio Take，原练习录音仍保留。

## 正式录制

在录制页选择前/后镜头、横/竖构图、镜像预览和歌词显示。点「检查设备与路由」，授权相机/麦克风，阅读真实输入、输出、剩余空间和蓝牙状态；可选择设备麦克风备用路径。确认输出后倒数 3 秒录制。摄像头无权限时可重新检查纯音频模式或到系统设置修复。

默认关闭人声耳返；系统明确报告有线耳机、采样格式和延迟门槛满足时可手动开启。蓝牙与无法确认终端的 USB 路径禁用耳返，伴奏照常播放。AirPods 路径、音质和声学同步需完成真实设备测试。不要在首次录制时假定它们已验证。

正式录制长按停止 1 秒，已有片段先保存再打开原始预览。预览是画面与干声；伴奏、效果和字幕在后期试听/输出合成。中断后确认路由，从默认回退 3 秒的位置接唱，或手工改变位置。新片段不会覆盖旧素材；后期可以调整切点。来电、后台、空间或热状态危险时尽力保存已完成片段；最后未封装的数据不能保证恢复。

录制中的时间、电平、锁和停止入口固定在底部。开启「锁定控制」会限制页面切换、设置和滚动；解锁与长按停止仍可使用。停止或中断后自动解除。此交互需在真实设备首次短录制时核对，不据编译结果假定误触保护已验收。

App 意外退出后，作品库「上次未完成的录制」列出已保存片段，可直接预览，或重新检查权限/路由后继续录入同一个 Take。接唱仍使用原 Take 的伴奏版本与变调，不会把后来选择的新伴奏写回旧录制。

不想继续时，可选择「保留文件并结束接唱」，无需重新授权麦克风。App 会先保护原日志和未登记的尾段字节，再结束恢复记录；无法关联 Take 的日志也会列出。已有 Take 保留，但未登记尾段没有可信时长或同步信息，不会被自动拼成虚构录音。

工程仍有未结束日志时，不能直接新建录制来覆盖它。请先从作品库续录原 Take，或使用上述保留收尾入口后再录新的 Take。日志无法关联时也适用。取消倒计时期间若文件已创建，会保留待恢复记录；没有已保存片段时不会显示录制保存成功。

## 后期与输出

选择 Take，调人声/伴奏音量、自然/温暖/轻混响预设，或展开 EQ、高通与混响。高通只减少低频杂音，不能移除所有噪声。固定偏移需要试听校准，不能代替演唱节奏修正。所有更改只保存参数，原始素材保留。

字幕可选择字体、字号、白色/黄色、位置、阴影与黑色描边宽度（0 为关闭，单位为输出像素）。描边随工程保存，预览和带字幕导出使用相同设置；无字幕视频不受影响。旧工程默认保持没有描边。

裁剪时间使用歌曲秒数。纯音频 Take 可选择相册照片生成视频，或导入/拍摄对口型画面；补拍不替换正式人声。补拍画面与参考声音可能存在偏移，需要预览与手工校准。

导出页首次勾选带字幕/无字幕两版，以后记住勾选，并将偏好用于新工程。缺少时间轴时先标记歌词，或取消带字幕视频。可以选择混音、干声、变调伴奏与歌词；音频可选 M4A/AAC 或 48kHz PCM WAV。默认视频 1080p/30fps，当前不开放 4K。失败项可单独重试，已完成项保留。Files 保存/分享需要本地先有足够渲染空间。

编辑页「试听当前混音」只生成音频试听。选择照片、补拍或视频 Take 后，可点「预览当前画面」，检查当前混音、裁剪、比例、镜像和逐句字幕。字幕开关只影响这次预览，不改导出预设；歌词尚未标记时明确采用无字幕预览。预览需要先准备媒体，关闭后释放自身缓存，原导出队列与成品保留。

完成导出的音视频项仍可点「预览此输出」，直接播放该成品文件，核对字幕、画面和声音后再保存/分享。

存储页或导出页的「全部成品与未登记文件」列出当前及历史版本，显示文件名、大小与时间，可逐个预览、保存到 Files、分享或两次确认删除。歌词可直接查看。未登记项可能是旧版文件或未完成输出，不会仅因文件存在就标为完成；请先核对，需要时单独保存副本。

## 工程包

作品库 → 工程备份与恢复：

- 完整：全部伴奏、Take、练习、歌词、编辑和必要素材，默认不含可重建成品，可勾选。
- 精简：当前编辑及依赖素材，排除未引用的旧 Take。
- 自定义：选择保留的 Take，并在包含成品时逐个选择当前或历史完成文件；系统强制补齐当前编辑依赖，被用作伴奏/画面等的文件不能移除。

生成后重新读取全部字节校验，再点「保存到 Files / Google Drive」。Google Drive 需已在设备系统 Files 中启用；App 不内置 Google 登录。

“包含已完成的导出成品”会读取历史目录，不限于最近一轮。未登记文件不自动装入工程包。修改备份类型、Take 或成品选择后，需要重新生成包，不能继续保存先前选项的旧包。

存储页「未引用原件与录制尾段」可将未登记 media 文件另存 Files、尝试播放或登记进完整包。登记仅确认原始字节与哈希，不代表可播放或已恢复同步。结束接唱时会自动登记保留的原件；精简/自定义包仍可能排除它们，请核对源文件排除数量，需保留全部字节时使用完整包。未登记的 exports 成品仍需单独保存。

三种状态必须分清：

1. 本地包已校验：只证明本地生成包可读取。
2. 已交给文件提供者：系统导出回调已返回，不证明云端上传完成。
3. 外部恢复已验证：从外部重新选择包并完整读取校验，不证明未来永久可用。

恢复同 ID 工程默认保留两份，也可在备份页选择先留旧工程安全副本再替换，不静默覆盖。可将包通过 Files 或 AirDrop 传给另一台设备，独立打开编辑；没有实时云同步。

## 释放与存储

释放本地素材前先核对包的范围和验证级别。精简/自定义包排除的 Take，若本地源素材被移除，不能从该包恢复。UI 有两次确认；最终由用户判断备份风险。归档后保留作品占位、备份记录和已导出成品；继续编辑源素材需要从外部包恢复。

源素材释放会保留已导出成品，界面数量与字节只统计将移除的源资产。需要进一步清理成品时，从成品目录选中具体文件并再次确认；不会随着源释放顺带删除历史版本。

有待恢复录制时，即使已有验证备份也禁止释放源素材。先从作品库重新检查并结束该 Take，重新备份当前内容后再确认释放。

未引用原件可逐个两次确认删除；任何伴奏、Take、封面或当前画面引用的文件均受保护。存在待恢复日志时禁止删除这些尾段，先保留收尾。复制工程会保留历史成品、日志和未登记原件，排除可重建缓存；复制失败的暂存可在存储页安全/恢复副本中查看和处理，不自动清除。

存储页区分原始素材、成品/临时渲染、试听缓存和安全/恢复副本。安全副本可以重新校验并导出为工程包，再从作品库导入恢复；未提交的恢复暂存未必可打包。移除所选副本需要两次确认，可能永久失去旧版本独有录制。删除指定 Take 也需两次确认且不能破坏其他编辑引用；缓存可重建。App 不在后台自动删除这些原件。退出前等待保存结束，首次真机测试用短的自有样本。

## 工程索引异常

若单个工程的索引损坏、缺失或身份不符，作品库会在「需要恢复的工程目录」单列它，其余可读工程继续显示。不会自动删除坏目录或静默用旧索引覆盖。

打开问题目录，可先逐个将原件保存到系统 Files，或选择外部 `.coverproject` 包保留两份恢复。文件存在不代表能播放；缓存不列出，符号链接或不受控目录拒绝读取。

若有上一版索引，点「校验上一版索引与全部登记素材」，确认标题、修订、Take 和素材数量，再创建独立恢复副本。App 核对登记文件大小与 SHA-256；索引已变化、素材缺失/损坏或上一版只是归档索引时，不生成可编辑副本。需要足够空间，失败暂存仍保留。

恢复副本使用新身份，原坏目录保留。它依据较旧索引，可能没有最近的编辑或 Take；额外尾段和原索引字节会保存在副本中，可由完整包保留，但不会自动拼接成缺失录音。待恢复日志仍需处理；未登记的成品需要单独保存。请实际预览并重新完整备份，原来的备份授权不会沿用来释放新副本源素材。

## 无法打开本地作品库

本地目录或根恢复事务打不开时，App 显示错误和「重试打开」，不会改用新空库或清空原目录。请先保留资料，不要把卸载 App 当作修复方式。

若页面列出可处理的恢复日志，会显示大小与 SHA-256。可以确认「保留事务日志并重新打开」：仅将当前日志停用并保留，工程和安全副本不移动、不删除。此操作可能让其他作品重新可用，不代表涉及的工程已恢复；请到作品库 → 存储管理检查安全/恢复副本，核对并从外部包恢复需要的作品。

保留日志可从启动页或设置 →「保留的启动恢复日志」另存 Files。安全/恢复副本即使索引已坏，也可选择「浏览并另存原件」逐文件保存，不必先生成有效工程包。原目录和文件不会因此移除。

不可读、超大或含符号链接的事务日志不会提供停用操作，需先解决设备存储/访问问题并保留原目录。启动失败期间从 Files 打开的工程包会明确显示尚未导入；处理好本地库后重新选择原包，外部文件不被修改。Files 接收另存文件仍不等于云端上传完成。

## 文件格式

`.coverproject` 不是 ZIP。使用流式 `COVERP01` 容器，头部是 8 字节 magic、8 字节大端清单长度、32 字节清单 SHA-256，随后是 UTF-8 JSON 和顺序原始素材。JSON 包括模型、版本、功能标志、身份/修订、每文件路径/大小/哈希及精确时间分数。当前 reader 支持 schema 1；未来版本或未知功能明确拒绝。媒体不压缩，避免重复编码和解压炸弹。请保留整个包，不要只复制清单。
